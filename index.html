Ключ OpenAI

Счета распознаёт ИИ от OpenAI, за распознавание платит владелец ключа: примерно 1–2 цента за счёт.

  1. Зайдите на platform.openai.com → Billing и пополните баланс (от $5).
  2. Там же → API keys → Create new secret key, права All. Скопируйте ключ — он начинается с sk-.
  3. Вставьте его сюда.

Ключ хранится только в этом браузере на этом компьютере и отправляется только в OpenAI.

С какой таблицей работаем?

Можно начать новую или продолжить вашу: сайт сам найдёт в ней колонки и будет дописывать строки в конец.

Колонки вашей таблицы

Что проверяется в каждом счёте:
  • количество × цена = сумма строки, сумма строк = итог, без НДС + НДС = с НДС;
  • каждое число и дата есть в самом PDF — если ИИ ошибся в цифре, строка станет красной;
  • если в счёте штуки, литры считаются из объёма в названии: 24 ks × «4 l» = 96 л;
  • повторно присланный счёт в таблицу не попадёт.
